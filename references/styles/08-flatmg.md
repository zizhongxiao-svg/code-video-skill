# 08 扁平 MG · Flat motion graphics

- **示例题材**：一个塑料瓶的回收之旅
- **适合**：循环流程、生活科普
- **时长**：12 秒　**技术**：Canvas 2D
- **示例源码**：[`examples/flatmg/`](../../examples/flatmg/)

![扁平 MG](../../assets/posters/flatmg.jpg)

## 精简版提示词（复制就能出个大概）

```text
用 Canvas 做 12 秒扁平 MG：纯色几何、无描边，每个场景换一块高饱和底色。
主角是会眨眼的塑料瓶：进回收箱、分拣、粉碎、熔融、抽丝，最后织成 T 恤。
没把握的数字不写，结尾推回第一帧做成循环；每帧只由 t 决定，先抽帧检查再出全片。
```

## 完整版提示词（示例成片就是用它跑出来的）

```text
用 Canvas 2D 做一段 12 秒、1920×1080、30fps 的「扁平 MG」科普动画：全部是纯色几何形状、没有描边和渐变，每个场景换一块高饱和纯色底（青绿/向日葵黄/珊瑚红/天蓝/紫/粉），机器用深藏青，背景漂着半透明的圆环、三角、点阵做装饰。
主角是一个有大眼睛和腮红的塑料瓶，走完“塑料瓶的回收之旅”：蹦进回收箱 → 传送带上过扫描门被认出是 PET → 掉进粉碎机变成一片晕乎乎的瓶片 → 跳进水槽洗澡、再跳进熔炉变成一团笑眯眯的熔体 → 从喷丝板挤出变成纤维，主角骑在纱线头上 → 来回穿梭织出一件 T 恤，最后变成 T 恤胸前的瓶子图案。
镜头在场景间横向快摇，主角有眨眼、惊讶、眩晕、开心等表情，跳跃带挤压拉伸和回弹，但不要弹得太夸张；每个场景左上角弹出编号标题，只标注可核实的事实（如“瓶子和涤纶衣服是同一种塑料 PET”），没把握的数字一律不写。
结尾镜头推进 T 恤上的瓶子图案，推到和第 1 帧完全一样的构图，做成无缝循环（第 1 帧只有主角和底色，其余元素都在之后弹出）；每一帧只由时间 t 决定，渲染后对比第 0 帧和第 12 秒那一帧，确认两帧一致。
```

## 制作手记

扁平 MG 就是扁平风格的动态图形。主角是一个会眨眼的塑料瓶，从回收箱、分拣、粉碎、熔融一路走到抽丝织成 T 恤，最后 T 恤上印着瓶子，能接回开头循环播。画面上的熔点只写了“250°C 以上”，因为提示词要求没把握的数字不精确到个位。

## 事实依据（notes.txt）

流程依据瓶到纤维（bottle-to-fiber）的再生 PET 工艺：回收→分拣（光学识别后用气流把目标件吹离传送带）→粉碎成瓶片→清洗→熔融（PET 熔点约 250–260°C，故写“250°C 以上”）→熔融纺丝（熔体经喷丝板细孔挤出、冷却、拉伸）→织造；涤纶即聚对苯二甲酸乙二醇酯（PET）纤维，见 Wikipedia “Polyethylene terephthalate”“Polyester”词条及 Textile Exchange 再生涤纶说明。
