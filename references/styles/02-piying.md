# 02 皮影讲典故 · Shadow puppet (皮影)

- **示例题材**：曹冲称象
- **适合**：成语、典故、历史小故事
- **时长**：11 秒　**技术**：Canvas 2D
- **示例源码**：[`examples/piying/`](../../examples/piying/)

![皮影讲典故](../../assets/posters/piying.jpg)

## 精简版提示词（复制就能出个大概）

```text
用 Canvas 做 11 秒彩色皮影戏：暖光透过幕布，角色分片拼成、绕关节转，朱红石绿配镂空纹样。
演曹冲称象：象上船刻记号，换石头装到记号齐水面，再称石头，结尾点破“等量替换”。
船的吃水按载重算，记号不能被水面盖住；每帧只由 t 决定，先抽帧检查再出全片。
```

## 完整版提示词（示例成片就是用它跑出来的）

```text
用 Canvas 2D 逐帧绘制一段 1920×1080、30fps、约 11 秒的彩色皮影戏：暖色灯光透过半透明幕布（中心亮、边缘暗角、布纹肌理、灯光轻微闪烁），上方挂朱红镂空帘幔，远山和祥云做成半透明剪影布景，幕布下方的深色木台放字幕。
所有角色都由头、身、臂、腿分片拼成，每片用朱红、石绿、赭石填色、黑色粗描边，内部挖出透光的铜钱纹、菱形纹、云纹镂空，各片绕关节点转动，并画出伸到幕布底边的半透明挑杆影子。
题材是曹冲称象：大象走上船、船身下沉，曹冲在水面齐平处刻下朱红记号；大象下船，记号露出水面；石头一块块装上船，直到记号齐水面；再把石头放上杆秤称重；结尾挂出“等量替换”牌匾，字幕点破“船吃水一样深，重量就一样”。
船的吃水深度要由船上载重直接算出，记号画在水面图层之上，始终可见。
所有动画只由时间 t 决定（不用随机数、不累积状态）；先抽 4–6 帧检查字幕是否 ≥36px、人物是否出画、记号与水线是否对齐，改完再全片渲染。
```

## 制作手记

人物由头、身、臂、腿分片拼成，绕关节转，还画出了挑杆的影子。船吃水多深是按船上载重算的，所以记号和水线能两次对齐。不足是结尾没把“象在船上”和“石头在船上”两个画面并排摆出来，“吃水一样深”少了一个对照。

## 事实依据（notes.txt）

典故出自《三国志·魏书·邓哀王冲传》：曹冲“置象大船之上，而刻其水痕所至，称物以载之，则校可知矣”；原理是阿基米德浮力原理——吃水深度相同，排开的水就相同，浮力和载重也就相同（人物造型、配色为艺术化处理）。
