# 01 汉字演变 · Chinese character evolution (3D)

- **示例题材**：「日」字怎么变成今天的样子
- **适合**：文字、器物、朝代更替
- **时长**：12 秒　**技术**：Three.js (WebGL)
- **示例源码**：[`examples/hanzi/`](../../examples/hanzi/)

![汉字演变](../../assets/posters/hanzi.jpg)

## 精简版提示词（复制就能出个大概）

```text
用 Three.js 做 12 秒「汉字演变」：近黑暗场、暖色火光、景深虚化、胶片颗粒。
「日」字依次刻在龟甲、青铜鼎、石碑、竹简、纸上，左下角写字体名和年代。
古字形宁可简洁也不能画错；每帧只由时间 t 决定，先抽帧检查再出全片。
```

## 完整版提示词（示例成片就是用它跑出来的）

```text
用 Three.js 做一段 12 秒、1920×1080、30fps 的“汉字演变 · WebGL 电影感”动画：近黑暗场加雾，每个物件旁有一盏暖色点光源当火光（亮度和位置的闪烁由 t 的几个正弦叠加算出），配发光火星粒子、BokehPass 景深（焦点跟着当前物件，其余虚化）、轻微泛光、暗角和胶片颗粒，物件之间镜头缓慢横移推近，下一个载体从画面右侧虚焦入画。
题材是「日」字怎么变成今天的样子，五个载体依次出场，材质全部用 canvas 程序化生成：甲骨文刻在龟甲上（有盾纹缝、钻凿灼痕和卜兆裂纹，字是刀刻的方圆框加中间一短横），金文在青铜鼎腹（铜绿斑驳、云雷纹带，字是圆框加中间一点），小篆刻在石碑上（拉长的圆角长方加中间一横，笔画等粗），隶书写在编绳竹简上（扁方、平直、末笔微微挑尾），楷书写在米字格纸上（扁笔锋书写的今天的「日」）。
古字形用自己画的路径生成颜色贴图和凹凸贴图，宁可简洁也不能画错；每个阶段左下角大字写字体名，下面写年代（商代 · 约前 1300 年 / 西周 · 前 1046—前 771 年 / 秦 · 前 221 年统一文字 / 汉代 · 前 206—公元 220 年 / 魏晋以后定型 · 沿用至今）和一句载体说明，右上角五个小圆标随进度点亮。
所有画面只由 t 决定（window.__render(t) 里同步 composer.render），粒子位置也用固定种子算出，不用 requestAnimationFrame 和 Math.random；抽帧检查字形是否贴近真实、文字是否压在亮处看不清、转场时有没有长时间空画面。
```

## 制作手记

这是这一组里唯一用 WebGL 做的三维画面。龟甲、青铜鼎、石碑、竹简、纸五个载体依次入画，火光闪烁和景深虚化都由时间算出来。古字形是模型自己画的路径，提示词里写了“宁可简洁也不能画错”；小篆配石碑、隶书配竹简，是按出土材料对应的。

## 事实依据（notes.txt）

依据：「日」的字形演变按常见文字学资料（《说文解字》“日，实也，太阳之精不亏，从囗一，象形”；汉典 zdic.net「日」字源字形；裘锡圭《文字学概要》）整理：甲骨文作方圆轮廓内一短横或一点（商代后期，盘庚迁殷约前 1300 年起），金文多为圆轮廓内一点（西周，前 1046—前 771 年），小篆为长圆角框中一横（秦前 221 年统一文字，秦刻石用小篆），隶书扁方平直（汉代通行，汉简与汉碑），楷书魏晋以后定型；载体搭配按史实取「小篆—秦刻石、隶书—汉简」，字形为手绘示意，未摹写具体某片甲骨或某件铜器。
