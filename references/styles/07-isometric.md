# 07 等距流程 · Isometric process

- **示例题材**：一张纸是怎么造出来的
- **适合**：生产线、工序、供应链
- **时长**：12 秒　**技术**：Canvas 2D
- **示例源码**：[`examples/isometric/`](../../examples/isometric/)

![等距流程](../../assets/posters/isometric.jpg)

## 精简版提示词（复制就能出个大概）

```text
用 Canvas 做 12 秒等距流程：30° 等距投影，青绿、橙、深蓝三色，配小车、蒸汽等细节。
讲一张纸怎么造出来：削片、制浆、漂白、抄纸、压榨烘干、卷取，每站从地面升起带编号标签。
最后拉远连成一条传送带；每帧只由 t 决定，先抽帧检查再出全片。
```

## 完整版提示词（示例成片就是用它跑出来的）

```text
用 Canvas 2D 做一段 12 秒、1920×1080、30fps 的「等距流程」科普动画：真 30° 等距投影（屏幕 X=(x−y)·cos30°，Y=(x+y)·sin30°−z），浅薄荷色底 + 浅色等距网格，主色只用青绿、橙、深蓝三种，立方体三个面按“顶亮、左中、右暗”上色，圆柱用渐变，配小树、管道、蒸汽、小车等细节。
题材是“一张纸是怎么造出来的”：①木材削片 ②蒸煮制浆 ③漂白 ④上网抄纸 ⑤压榨烘干 ⑥卷取成卷，每个环节是一块微缩平台，按顺序从地面弹起、机器逐件长高，头顶弹出带编号的白色胶囊标签，底部字幕用一句话讲清这一步在做什么（只写可核实的事实，比如“浆料里 99% 以上是水”）。
镜头先贴近跟拍每个环节，9 秒后拉远看全景，一条传送带从第 1 站一路画到第 6 站，带上依次跑木片、褐色纸浆、白纸浆、纸张，最后一句话总结整条链路。
每一帧只由时间 t 决定（随机用固定种子），物体按 x+y 深度排序绘制；渲染后抽 4–6 帧检查：标签和字幕不重叠、不出画，手机缩小看正文字号仍 ≥36px。
```

## 制作手记

六个工位依次从地面升起，带编号标签，最后拉远连成一条线。工序按真实的化学法制浆造纸来排，六步都写在下面的提示词里。小卡车、蒸汽、传送带上的纸浆这些细节，提示词里点名要了。

## 事实依据（notes.txt）

流程依据化学法（硫酸盐法）制浆造纸的标准工序：削片→蒸煮（NaOH+Na2S 碱液溶出木质素）→无元素氯漂白（二氧化氯、氧气等）→长网成形（流浆箱上网浓度约 0.1%–1%，即 99% 以上是水）→压榨与蒸汽烘缸干燥→卷取分切，见 Smook《Handbook for Pulp & Paper Technologists》及中国造纸协会公开科普资料。
