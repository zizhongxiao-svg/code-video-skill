# 03 像素典故 · 16-bit pixel art

- **示例题材**：守株待兔
- **适合**：寓言、梗、游戏化叙事
- **时长**：12 秒　**技术**：Canvas 2D
- **示例源码**：[`examples/pixel/`](../../examples/pixel/)

![像素典故](../../assets/posters/pixel.jpg)

## 精简版提示词（复制就能出个大概）

```text
用 320×180 小画布画 16 位像素风，整数倍放大到 1080p，点阵字配 RPG 对话框。
演守株待兔，5 个场景硬切，最后切回现代：一个人盯着手机等爆款。
远景主角至少占画面高度的四分之一；每帧只由 t 决定，先抽帧检查再出全片。
```

## 完整版提示词（示例成片就是用它跑出来的）

```text
用 320×180 的低分辨率 Canvas 画 16 位像素风场景，CSS 放大到 1920×1080 并设 image-rendering: pixelated；调色板有限，角色带 1 像素深色描边，天空用色带加棋盘格抖动过渡；文字层用 640×360 画布写 Noto Sans CJK 后把 alpha 二值化，得到真正的点阵字，配 RPG 风格对话框逐字打出。
题材「守株待兔」（《韩非子·五蠹》），12 秒内硬切 5 个场景：农夫耕田（远景）→ 兔子狂奔撞上树桩，震屏、「咚！」、四脚朝天、眼冒金星（特写，整场像素放大 2 倍）→ 农夫举着兔子跳起来 → 扔下锄头坐在树桩旁，日升月落快进，田里荒草越长越密 → 硬切回现实：现代人坐在树桩形凳子上盯着手机等爆款，墙上时钟飞转，最后大字点破「偶然撞上的好运，不会自己重复」。
所有动画只由 t 推导，动作帧按 4–12fps 步进更有像素感，随机数用固定种子。
抽帧检查角色是否太小、字幕框是否挡住主体、各场景是否一眼看懂，改完再全片渲染。
```

## 制作手记

320×180 的小画布整数倍放大，字也做成了真点阵，配 RPG 对话框逐字打出。五个场景之间直接硬切，最后一个镜头切回现代：一个人盯着手机等爆款，跟守株待兔是一个意思。远景里农夫在成片上只有一百多像素高（整个画面高 1080），手机上看偏小；自己做的话，提示词里再加一句：远景主角至少占画面高度的四分之一。

## 事实依据（notes.txt）

出自《韩非子·五蠹》：“宋人有耕者，田中有株，兔走触株，折颈而死，因释其耒而守株，冀复得兔，兔不可复得，而身为宋国笑。”原文中兔子折颈而死，画面改成撞晕倒地属于艺术化处理；“两千多年后”按韩非（约前280—前233年）推算；现代人等爆款的一段是寓意延伸，不是史实。
